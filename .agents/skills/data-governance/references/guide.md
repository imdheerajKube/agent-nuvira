Data governance: policies, access controls, compliance, and stewardship. Use when implementing data governance frameworks.

## Goal pattern

data governance policies access control compliance stewardship GDPR CCPA

## Steps

0. [context-gatherer] Assess governance needs: what regulations apply? What data is sensitive? What access controls exist?

1. [planner] Design governance framework:
1. Policies: data handling, retention, disposal
2. Access: RBAC, data classification
3. Compliance: GDPR, CCPA, HIPAA
4. Stewardship: ownership, accountability
5. Cataloging: data inventory, metadata
6. Auditing: access logs, compliance checks (after: 'step-0')

2. [runner] Implement governance:
1. Define data policies
2. Implement access controls
3. Configure compliance rules
4. Assign data stewards
5. Create data catalog
6. Set up auditing (after: 'step-1')

3. [reviewer] Verify: policies are defined, access is controlled, compliance is met, catalog is complete. (after: 'step-2')
