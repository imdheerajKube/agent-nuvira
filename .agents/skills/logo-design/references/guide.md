## Steps

0. [context-gatherer] Map the brand: what is the company/product name? What industry? What style (modern, classic, playful, minimal)? What colors? What competitor logos exist? What output format (SVG, PNG, PDF)?

1. [planner] Design the logo approach:
1. Concept: 3 logo directions (wordmark, lettermark, symbol)
2. Typography: select fonts (Google Fonts or custom)
3. Color: primary + accent colors with contrast ratios
4. Variations: horizontal, stacked, icon-only, dark/light
5. Export: SVG (scalable), PNG (web), PDF (print)
6. Brand guide: usage rules, spacing, minimum size (after: 'step-0')

2. [runner] Create the logo:
1. Generate SVG logo with the chosen concept
2. Create color variations (full color, monochrome, reversed)
3. Export to required formats
4. Create a simple brand guide document
5. Test on different backgrounds and sizes (after: 'step-1')

3. [reviewer] Review: check scalability (resize to 16px and 1000px), verify contrast ratios, test on dark/light backgrounds, confirm export quality. (after: 'step-2')
