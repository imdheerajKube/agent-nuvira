## What this run supports

- **Best recall@5 in this run: semantic (bge-small), 95%.** That is one synthetic fixture, one run, and 20 answerable cases; it is not a production estimate.
- **Keyword false positives: 0 of 3 unrelated questions.** The no-content guard now returns no hits when a query has no content terms. Its typo score is 2/4; removing the accidental stopword matches can cost a case that only ranked because a function word appeared inside a word.
- **Identifier-aware tokenization: BM25 moves from 80% to 85% recall@5, MRR 0.70 to 0.78.** It recovers dotted and hyphenated identifiers without a model.
- **Trigram/edit fallback: 80% to 95% recall@5, MRR 0.70 to 0.85, at under 1 ms/query.** It reaches typo 4/4 with no embeddings.
- **Semantic vs best lexical: recall@5 95% vs 95% (+0%), MRR 0.89 vs 0.85 (+0.04), at 100 ms vs 0 ms per query.**
  On this fixture, the cheap lexical arm matches or beats semantic recall. Do not pay the embedding cost for this result.
- **Hybrid did not beat semantic on recall@5** (95% vs 95%), and its MRR is 0.86 vs 0.89. RRF is not justified by this fixture.
- **Semantic still misses 1 paraphrase case:** "Who gets woken?". It is not a general paraphrase fix.

## Recommendation

1. **Make the lexical upgrade the candidate, not embeddings.** Identifier-aware tokenization plus the typo fallback matches or beats semantic recall on this run at under 1 ms/query. That is the cheaper change to validate on real questions.
2. **Run the benchmark on real attachment questions before shipping either upgrade.** This report is directional; the fixture labels are authored. Supply a `--fixture` JSON with `source: "real"`, real attachment files and the exact passage each question should retrieve.
3. **Do not choose hybrid.** It did not improve recall over semantic here and has the extra lexical-plus-dense complexity. Add fusion only when a real eval shows complementary misses.
4. **If semantic still wins on real queries, use semantic-only as the candidate.** Do not add embeddings for the synthetic fixture alone.

## Limits

- Synthetic documents and authored labels; one query per case. Exact/paraphrase/typo labels are not user-labelled.
- The semantic floor is the production knowledge-base default (0.5), not tuned on this fixture. A different floor would change the leak/recall trade-off.
- The cold index time includes model load. A deployed process would warm the model and precompute embeddings at ingest, so this is not a steady-state cost.
- Only 20 answerable cases. A one-case difference is visible in every percentage point; treat the ranking as directional.
- Real-query validation is not included: no captured user attachment questions were available in this checkout. Supply a `--fixture` JSON with `source: "real"` to run that set.
